# DISPO for Android

Signed APK releases of [DISPO](https://dispoapp.net), the app for musicians, for Android phones outside the Play Store.

Install: download the `.apk` from the [latest release](https://github.com/ludovic111/dispo-android/releases/latest) on your phone, open it and allow the installation when Android asks.

Once installed, the app finds new releases here by itself and offers to update.

This repository only holds releases; the source code is not published here.
